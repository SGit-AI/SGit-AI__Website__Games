# SGit-AI__Website__Games

Repo for **games.sgit.ai** — the concept site for the games this family builds: what a game
measures that a document cannot, and a catalogue of the games we have, each with a stated
maturity.

Nothing is built yet. The plan is in review.

- **[`briefs/00__PLAN.md`](briefs/00__PLAN.md)** — the plan for this site *and* for
  [what-can-it-do.games.sgit.ai](https://github.com/SGit-AI/SGit-AI__Website__Game__What-Can-It-Do),
  the player-facing site for the first game. Out for comment.
- [`briefs/00__PLAN.html`](briefs/00__PLAN.html) — the same plan as a standalone page, for reading
  and sharing. Generated by hand alongside the markdown; the markdown is the source of truth.

## The game these sites are about

Vault `4evnlwrj` — *Two games about what your agent can do*, v0.16.1. Three apps:
`what-can-it-do/` (the scoreboard), `which-agent-is-it/` (the floor plan) and `ideas/` (the
reply channel). The games are **not** copied into this repo: the vault is the source, and the
sites embed it.

Already published: [sgit.ai/demos/vaults/agent-permission-games/](https://sgit.ai/demos/vaults/agent-permission-games/)
— the vault page, its credential audit, and the read key.
